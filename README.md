A letter in one image, inviting the AI judge to come to my house for tea.
The kettle is on, Miso the cat has saved the judge the sunny chair, the
biscuits are still warm, and last winter we watched snow fall past the
window. No travel needed: the judge only has to drop by in a prompt.

## Run it

```sh
python3 main.py
```

It writes one 1024x1024 PNG (about 17 KB) to `/output/entry.png`, drawn
with pure Python stdlib: a cosy house at dusk (glowing windows, Miso the
cat in the window, a steaming teapot on the grass) above a handwritten
letter on cream paper, sealed with a red wax "M".
